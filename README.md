College Canteen Food Ordering System

Project Overview

The College Canteen Food Ordering System is a web-based application designed to simplify food ordering in a college canteen.

Objectives

- Reduce waiting time in the canteen.
- Allow students to view available food items.
- Make food ordering easier and more convenient.
- Improve canteen order management.

Technologies Used

- HTML
- CSS
- JavaScript

Project Type

Academic Project – MCA First Semester

Author

Khushi Yadav
## Project Features

- View available canteen food items
- Check food prices
- Place food orders
- View order details
- Basic CI workflow configured for the College Canteen project.
